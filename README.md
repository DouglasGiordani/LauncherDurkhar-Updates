# Launcher Durkhar - Atualizações

Repositório público apenas com os binários de atualização automática do Launcher Durkhar (update.zip e ersion.json).

## Como publicar uma nova atualização
1. Execute gerar_update.ps1 (informando a nova versão e notas) ou atualize update.zip e ersion.json com o novo sha256.
2. Abra o **GitHub Desktop**, faça **Commit** e clique em **Push origin**.
3. Quem já tem o launcher só precisa abrir **ActualizarLauncher.exe** (ou **Extras -> Buscar Actualizaciones...**).
